# Future product photography

Place the approved, non-stock product photography in this folder with these filenames:

- `hero-hang-tag-detail.jpg` for the hero close-up
- `hang-tag-range.jpg` for the featured hang tag product image
- `factory-printing-floor.jpg` for the manufacturing image

The homepage currently uses designed placeholders. When the photographs are ready, update the `futurePath` values passed to `ProductImage` in `app/page.tsx` to the matching `/images/...` path. Keep the existing descriptive `alt` text aligned with the final photo.
